# Music Downloader

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | **[Русский]** | [Español](README.es.md) | [Français](README.fr.md)

Пакетный загрузчик плейлистов NetEase Cloud Music с графическим интерфейсом на Electron.

Вставьте ссылку на плейлист или его ID, выберите уровень качества — и загрузчик скачает весь плейлист, автоматически записав теги ID3 и обложку.

## Возможности

- Поддерживаются ссылки на плейлисты, ID плейлистов, ссылки на альбомы, ссылки на чарты и файлы-списки `.txt` (каждая строка начинается с ID песни)
- 10 уровней качества: standard / higher / exhigh / lossless / hires / jymaster / jyeffect / sky / vivid / dolby
- Если запрошенный уровень недоступен, загрузчик автоматически понижает качество по цепочке и помечает это в журнале
- Счётчики прогресса в реальном времени (успешно / пропущено / ошибок / только превью) и прокручиваемый журнал
- Вход по QR-коду или вставка cookie — для треков VIP и без потерь
- Докачка (существующие файлы больше 10 КБ пропускаются); автоостановка, если свободного места на диске меньше 1,5 ГБ
- Встроенный сервер NetEase API (`@neteasecloudmusicapienhanced/api`), отдельный процесс не нужен

## Структура проекта

```
src/core/       ядро загрузки (download.js / match.js / login.js / rules.json)
src/main/       главный процесс Electron и preload
src/renderer/   интерфейс (HTML / CSS / JS)
```

## Разработка

```powershell
npm install
npm start
```

### Сборка установщика

```powershell
npm run dist
```

Результат в каталоге `release/`:
- `MusicDownloader-Setup-<version>.exe` — установщик NSIS
- `win-unpacked/MusicDownloader.exe` — версия без установки

## Командная строка

`src/core/download.js` работает и без графического интерфейса:

```powershell
node src/core/download.js <ссылка-на-плейлист|ID|songs.txt> --level sky --out D:\Music
```

Основные параметры:

| Параметр | Описание |
|---|---|
| `--level` | Уровень качества, по умолчанию lossless |
| `--chain` | Цепочка понижения через запятую, например `jymaster,lossless` |
| `--out` | Каталог вывода |
| `--cookie` / `--cookie-file` | Cookie для входа |
| `--concurrency` | Число параллельных задач, по умолчанию 4 |
| `--limit` | Скачать только первые N треков |
| `--no-tag` | Не записывать теги и обложку |
| `--dry-run` | Только получить список треков, без загрузки |

Требуется локальный сервер API:

```powershell
$env:PORT=3001; node .\node_modules\@neteasecloudmusicapienhanced\api\app.js
```

## Примечания

- Без входа треки VIP отдаются только 45-секундным превью; скрипт это распознаёт, пропускает трек и записывает его в `_result.json`
- Cookie для входа хранится в каталоге пользовательских данных — **не коммитьте её в репозиторий**
- Права на скачанные записи принадлежат правообладателям; используйте их только в личных законных целях

## Зависимости

- `@neteasecloudmusicapienhanced/api` — NetEase API (форк, поддерживаемый сообществом)
- Electron / electron-builder
- ffmpeg (для тегов и обложки, должен быть в `PATH`)
